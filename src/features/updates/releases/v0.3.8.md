# Localtify 0.3.8 — Stability & Polish Update 🎧

Localtify 0.3.8 is a cleanup, stability, and release-quality update focused on making the big 0.3.7 foundation feel finished. This release polishes Albums V2, improves playback/download reliability, cleans up settings and visuals, and makes the Linux release feel more official.

## Main Highlights ✨

### Albums V2 Polish

* Improved the Albums section so custom albums feel more built into the app.
* Cleaned up album shelves, album cards, spacing, and detail page behavior.
* Improved album cover handling and custom cover display reliability.
* Polished album actions so managing local albums feels smoother and less patched together.

### Playback & Audio Stability

* Improved the playback engine for more reliable daily listening.
* Cleaned up volume behavior and faster volume setting changes.
* Added more stability around background audio and saved playback settings.
* Improved missing-file recovery behavior so broken library entries are easier to handle.
* Reduced chances of playback breaking because of stale or missing local file paths.

### Downloads & Import Reliability

* Improved YouTube/download flow reliability for local music importing.
* Kept the main YouTube-to-audio feature intact while cleaning the surrounding release behavior.
* Improved download settings copy and folder handling.
* Cleaned up failed/finished download behavior so the app feels less messy after use.

### Metadata & Cover Tools

* Added/cleaned cover metadata tools for missing covers.
* Improved metadata cleaner preview behavior.
* Added safer actions for cleaning selected metadata.
* Added undo support around recent metadata cleaning work.
* Improved cover cache handling and missing-cover filtering.

### Settings Cleanup

* Reworked the settings pages into a cleaner, calmer layout.
* Removed unfinished or confusing controls that were not properly wired.
* Cleaned up Appearance, Library, Downloads, Covers, Updates, About, and Advanced sections.
* Removed old broken settings hero/card clutter.
* Made settings feel more like a real app page instead of a pile of patches.

### Theme & Visual Polish

* Cleaned up theme handling and custom theme behavior.
* Improved live theme editing so color changes feel faster and less laggy.
* Reduced visual replay/animation lag while editing settings.
* Cleaned up theme variables and release-safe styling.
* Removed hidden/old background styling that caused visual conflicts.
* Kept the app dark, solid, and readable instead of relying on unstable transparency tricks.

### Sidebar & Navigation Polish

* Reworked sidebar styling to be more stable and release-safe.
* Added cleaner sidebar icon motion and a Discord-style active indicator.
* Removed broken hover-shift behavior that caused layout problems.
* Improved sidebar readability and reduced CSS conflicts.
* Made the sidebar feel more consistent across Home, Library, Albums, Settings, and other pages.

### Onboarding Improvements

* Updated onboarding visuals and theme icons.
* Cleaned up the onboarding logo/title layout.
* Improved first-run styling so the app starts cleaner for new users.
* Kept onboarding lightweight and more polished without turning it into a full redesign.

### Cat Buddy Polish 🐾

* Added and refined the small cat buddy feature.
* Improved sprite animation handling.
* Fixed direction/movement behavior across multiple passes.
* Cleaned up the cat buddy styling so it works better with the release-safe UI.

## Linux Release Improvements 🐧

* Prepared Localtify 0.3.8 for Linux AppImage release.
* Updated Linux install copy to match the 0.3.8 AppImage name.
* Fixed Linux build problems caused by Windows `node_modules`.
* Confirmed Fedora needs a fresh Linux clone/build folder instead of building from `/run/media/...`.
* Fixed Linux release icon problems by generating proper `build/icon.png` and `build/icon.ico`.
* Built the Linux AppImage successfully as:

`localtify-0.3.8-x86_64.AppImage`

## Windows Release Improvements 🪟

* Published the Windows build for Localtify 0.3.8.
* Updated the version flow so the TypeScript app version matches `package.json`.
* Refreshed the `v0.3.8` tag so the release points to the correct latest commit.
* Cleaned up the release process so Windows and Linux builds both target the same 0.3.8 release.

## Version & Release Fixes 🛠️

* Updated the app’s internal TypeScript version from `0.3.7` to `0.3.8`.
* Updated the in-app “What’s New” changelog from old 0.3.6 text to proper 0.3.8 release notes.
* Updated shared constants/types/utils comments to match the 0.3.8 release pass.
* Fixed Linux install text so it no longer references the old 0.3.7 AppImage.
* Matched the app version with `package.json` so the release does not show mixed versions.

## Performance & Stability

* Reduced heavy pointer/proximity motion on large lists and cards.
* Kept motion focused on sidebar, player, and hero controls.
* Improved library performance by keeping heavy reductions in the worker.
* Reduced CSS conflicts from old App/Core/Home/Settings patches.
* Removed unstable transparent/acrylic-style behavior from the release-safe build.
* Improved overall UI consistency across the main app shell.
