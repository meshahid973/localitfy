### What changed in v0.3.7

Big changes here. Linux is now supported, and the main new feature is the new album section, suggested in the Issues area by @Crocodile73.

Some performance changes have also been made, and the onboarding has been fully rewritten for new users.

### New features

Added a new Albums section.

Local albums are now built from your existing music metadata.

You can create your own local albums from songs already in your library.

Custom albums can have their own title, artist, year, and cover.

Added a custom album cover picker.

Album covers now auto fit properly inside album cards.

Added album detail pages with play, shuffle, queue, edit, and track list controls.

Added support for albums with different artists, including various artists albums.

Added Linux build support.

Added AppImage support for Linux.

Added DEB support for Ubuntu and Debian based systems.

Added RPM support for Fedora and openSUSE based systems.

Added Linux release workflow support through GitHub Actions.

Added Linux icon generation for release builds.

### Onboarding

Fully rebuilt the first time setup screen.

Existing users will also see the new onboarding once.

After finishing or skipping onboarding, it will not show again.

Onboarding now runs as its own clean first run screen instead of sitting on top of the full app.

Improved onboarding theme selection.

Improved onboarding import flow.

Added smoother onboarding motion and a cleaner intro.

Removed old onboarding CSS from the main app CSS and moved it into its own onboarding stylesheet.

### Downloads and Spotify

Fixed Spotify packaged app issues where users could get missing client ID errors.

Improved Spotify public import behavior.

Improved Spotify connection status.

Improved Spotify playlist fetch layout.

Fixed broken Spotify track cards in the downloads page.

Improved download page layout and spacing.

Improved the public playlist message for Spotify imports.

Cleaned up old CSS patches that were fighting each other.
