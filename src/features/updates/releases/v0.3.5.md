# localtify v0.3.5

well that took quiet long, basically checked every single css code in localtify and there were atleast 20 old patch code in a single 12k line file now imagine how many in other files. anyway removed all of them fixed performance problems and some cool features

## Fixed

### Local audio playback
- Fixed songs showing as unsupported or missing even when the file existed.
- Reworked playback so local files no longer depend on stale saved audio URLs.
- Playback URLs are now generated safely at runtime from the real file path.
- Improved handling for old library songs, newly imported songs, and downloaded tracks.
- Reduced cases where playback state could get stuck after a failed play attempt.

### Packaged app startup
- Fixed a packaged-build issue where the installed app could open to a blank screen.
- Improved how the app loads its production renderer files.
- Kept production security stricter while fixing the local file loading issue.

### Cover loading in production
- Fixed pixel/fallback covers not loading correctly in the installed build.
- Added proper packaged resource support for the `pixelart` cover folder.
- Fixed cover paths behaving differently in `npm run dev` vs the public installer.
- Fixed the home hero album cover becoming stretched, cropped, or letterboxed.

## Improved

### Home hero/player layout
- Fixed long song titles pushing controls out of place.
- Restored the expanded hero so it feels larger again.
- Improved compact/expanded player layout balance.
- Made the album cover a proper normal square again.
- Improved artist text and action button spacing.

### UI motion and polish
- Added softer button press/squish interactions.
- Improved search bar focus motion.
- Added frosted-style hero action buttons.
- Improved update banner motion.
- Added a small Yukari update peek animation.
- Added update-state animations like bounce/shake behavior.
- Kept motion smooth without adding tilt.

### Build and release reliability
- Added packaged resource handling for cover assets.
- Cleaned up release build behavior.
- Improved Windows packaged app testing flow before publishing.

## Notes

If you downloaded the first early `0.3.5` installer and the app opened to a blank screen or covers did not load, please download and install the latest `0.3.5` installer again from GitHub Releases.

This version should be the proper fixed build.
