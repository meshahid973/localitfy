# localtify v0.3.3 ✨

this update is mostly cleanup after a bunch of stuff felt confusing, unfinished, or just slightly annoying.

the main thing: localtify should be easier to understand now, especially for new users. onboarding explains the app better, themes actually switch properly from settings, the update notice is cleaner, and Discord now behaves more like a real music app instead of showing some awkward “playing” status.

## changed 🎧

- onboarding is clearer now and explains the important stuff without throwing a wall of text at you
- YouTube-to-MP3/downloads are explained better for new users
- themes now actually apply properly from settings
- the update popup is now a cleaner top bar instead of a weird floating box
- the Updates settings page looks less like debug UI
- Discord activity now uses the proper listening-style presence
- compact/expanded player switching feels smoother
- album art now grows into the expanded player instead of just snapping bigger
- big song lists should feel smoother thanks to better rendering work

## fixed 🛠️

- fixed theme switching not visually updating the app
- fixed update UI looking messy and badly aligned
- fixed update text showing the wrong version in some places
- fixed Discord showing the wrong activity type
- fixed some TypeScript errors from the performance work
- fixed player expansion feeling jittery
- fixed album cover popping during expand/collapse

## performance ⚡

worked on large-library smoothness, player progress updates, cover/ambience handling, and transition jank.

nothing major was removed — blur, ambience, animations, Discord, downloads, playlists, and the normal localtify style are still here.

## note 🖤

this is not a huge feature update. it is more of a “make the app feel less confusing and less unfinished” update.
