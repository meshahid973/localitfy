## Changelog ✨

### 🚀 Performance and optimization

* Improved overall app smoothness across the main UI.
* Reduced unnecessary heavy visual effects in important areas.
* Cleaned up parts of the CSS to reduce duplicate/unused styling.
* Improved page responsiveness and reduced choppy behavior in heavier screens.
* Improved library/home scrolling stability.
* Reduced UI clutter in Downloads and other panels.
* Kept motion/proximity effects more controlled instead of applying them everywhere.
* Improved lightweight behavior for Linux and lower-end systems.

### 🎨 User experience improvements

* Reworked the first-run onboarding experience to feel cleaner and more welcoming.
* Improved onboarding copy to better explain Localtify’s local-first purpose.
* Added a peeking mascot to onboarding for a cuter first impression.
* Improved onboarding spacing, footer behavior, and step layout.
* Cleaned up unnecessary onboarding pills and noisy UI parts.
* Improved empty states so the app feels less plain when there is no content.
* Improved button spacing and visual consistency across multiple pages.
* Made Settings cleaner and easier to understand.
* Moved more advanced/scary options into Advanced so normal settings feel less confusing.

### 🐱 Mascot states

* Added multiple mascot states for different app situations.
* Added mascots for empty states, success, info, warning, danger, error, and loading.
* Added mascot support in onboarding.
* Added mascot support in settings helper areas.
* Added mascot support for warning/danger situations.
* Reduced mascot spam in Downloads so errors appear in one main place instead of repeating everywhere.
* Added mascot debug/testing support during development.

### 📥 Downloads improvements

* Improved the Downloads page layout and error handling.
* Added clearer download helper states.
* Added retry failed actions.
* Added copy error actions.
* Added open downloads folder actions.
* Added clear finished and clear failed actions.
* Improved failed download handling so errors are easier to understand.
* Reduced duplicate failed download areas so one main error card handles the problem.
* Improved Spotify fetch/download error display.
* Improved download queue and finished download cleanup behavior.

### ⚙️ Settings cleanup

* Cleaned up Appearance settings.
* Improved live cover color settings.
* Added clearer advanced appearance navigation.
* Improved advanced/danger settings with mascot support.
* Reduced hover/outline noise in settings.
* Improved settings section spacing and readability.
* Kept normal settings simpler while moving heavier tools into Advanced.

### 🪟 Windows improvements

* Improved Windows media integration.
* Improved tray/menu support.
* Improved taskbar media button handling.
* Improved play/pause, previous, and next command bridge behavior.
* Improved native media state syncing between the app and Electron.
* Improved preload/main bridge consistency.
* Improved Windows release readiness.

### 🐧 Linux improvements

* Improved Linux runtime behavior.
* Improved Linux/AppImage release quality.
* Improved Linux platform copy and setup text.
* Improved Linux desktop polish.
* Improved binary/runtime handling for Linux builds.
* Added more Linux testing focus for 0.4.0.

### 🎵 Player and library polish

* Improved player behavior and app stability.
* Improved player/media state handling.
* Improved library empty and missing file states.
* Improved missing-file and missing-cover related UI.
* Improved album/library spacing and layout consistency.
* Improved cover handling and visual polish.
* Improved overall local library feel.

### 🧹 Cleanup and stability

* Removed some old unused CSS safely.
* Cleaned up duplicate/old UI styling where it was obvious and low-risk.
* Improved file/type structure for future cleanup.
* Added safer type bridges to reduce TypeScript missing module issues.
* Improved platform integration checks during development.
* Avoided risky last-minute rewrites before release.

### 💬 Feedback

* Added `/feedback` support so users can send feedback more easily.
* Feedback is especially helpful for bugs, UI issues, downloads problems, Linux testing, and general improvement ideas.

## Thank you 💖

Thank you for 100+ users using Localtify. It genuinely means a lot.

0.4.0 is one of the biggest polish updates so far, and the goal is simple: make Localtify feel like a real, cute, smooth, local music library app.
