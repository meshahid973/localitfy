# Localtify 0.3.9

Localtify 0.3.9 is a quick stability update focused on fixing the bugs that made 0.3.8 feel rough in real use.

This is not a huge feature release. It is mainly here to clean up the important stuff before 0.4.0.

## What changed

### Spotify imports are safer now

This update improves the Spotify import flow so Localtify is less likely to grab the wrong song with the same or similar name.

Before, Spotify metadata could look correct in the app, but the downloaded audio underneath could still be a random matching result. 0.3.9 makes the matching stricter and keeps Spotify tracks tied to their proper import result more reliably.

### Song editing is back in the right-click menu

Thanks to @Void-gg7 for reporting that song names and artists could not be edited properly anymore.

The right-click menu now has **Edit song data** again, so you can edit the song title, artist, and album from inside Localtify.

For now, the broken cover actions were removed from the right-click menu so the menu only shows actions that actually work properly. Cover tools will get a cleaner rebuild later in 0.4.0.

### Local album importing is more reliable

Thanks to Crocodile73 for asking about local album importing.

The album buttons have been fixed so adding albums and importing album folders actually opens the proper folder/import flow again.

### Missing library files are easier to clean up

The Library now properly shows songs that still exist in Localtify but are missing from disk.

You can switch to the missing-files view and remove broken entries from the library without touching real music files that still exist.

### Feedback now works properly

0.3.9 adds a working feedback popup so users can report bugs or send suggestions more easily.

You can open it by typing:

```txt
/feedback
```

or:

```txt
feedback
```

The feedback system can send reports to a Discord webhook when configured by the app build.

### Analytics cleanup

Analytics were cleaned up to feel less invasive.

Removed from analytics:

* screen bucket
* CPU thread bucket
* device memory bucket
* timezone/local-time style tracking

Country/region-level locale info is still kept so it is possible to understand where users are roughly using Localtify from without collecting unnecessary device details.

### Security and CodeQL fixes

0.3.9 also fixes some security/check issues:

* replaced weak random ID fallback in analytics
* cleaned up Discord feedback webhook handling
* improved packaged `.env` loading for feedback builds
* fixed broken CSS selector issues in settings

## UI polish

A few small UI problems were cleaned up too:

* cleaner Library missing-files section
* better spacing in the Library area
* cleaner song context menu
* improved feedback popup styling
* fixed ugly text glyphs in buttons
* improved edit song modal controls
