# localtify v0.3.4 ✨

this update is mostly about making localtify feel smoother, lighter, and a bit less messy.

nothing huge got added here. this is more of a cleanup update after a few parts of the app started feeling rough. Settings should feel smoother now, the update ribbon feels less stiff, the app package is smaller, and some of the giant Settings code has finally been moved out of `App.tsx`.

## what changed

• Settings pages now switch with smoother motion instead of snapping instantly

• the update ribbon now slides in more naturally and feels less awkward

• the in-app changelog has been updated for v0.3.4

• the big Settings renderer was moved out of `App.tsx` into its own file

• the build setup was cleaned up, which helped reduce the app size

• blur, ambience, animations, Discord, downloads, themes, and the usual localtify style are all still here

## fixes

• fixed the broken Settings import after splitting the file

• fixed TypeScript issues in the new Settings component

• fixed Settings pages feeling too instant when switching categories

• fixed the update ribbon motion feeling too heavy

• fixed extra build/package bloat from files and dependencies that did not need to be shipped

• fixed the Windows build problem by moving the project out of OneDrive

## performance

• the installer is smaller now

• Settings motion feels smoother

• `App.tsx` is a little lighter after moving Settings into its own component

• packaged app size was reduced without removing ffmpeg, downloads, blur, ambience, or Discord

• no bottom player layout changes in this update

## note

this is not a big feature update.

it is mostly a cleanup release to make localtify feel smoother, lighter, and easier to work on.
