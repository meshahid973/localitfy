# Security Policy

## Supported Versions

Localtify is still early in development, so security updates are focused on the newest public release.

| Version | Supported       |
| ------- | --------------- |
| 0.3.7   | Yes             |
| 0.3.x   | Limited support |
| < 0.3.0 | No              |

If you are using an older version, please update to the latest release before reporting a bug. Some issues may already be fixed in the newest version.

## Reporting a Vulnerability

If you find a security issue in Localtify, please report it privately instead of opening a public GitHub issue.

You can contact me through either of these:

Discord: `.coderpixel`
Email: `coderpixelbusiness@gmail.com`

Please include as much useful detail as you can, such as:

* what version of Localtify you are using
* what operating system you are on
* what the issue is
* steps to reproduce it
* screenshots or logs if they help explain the problem

I will try to review security reports as soon as possible. If the issue is accepted, I will work on a fix and include it in a future update. If the report is not a security issue, I may still treat it as a normal bug report.

Please do not publicly share exploit details until a fix has been released.
