# localitfy

**localitfy** is a Spotify-inspired music player for people who want their own local music library, clean UI, cute album art, listening stats, and Discord Rich Presence without needing a streaming service.

It is built as a desktop app using **Electron**, **React**, **Vite**, and **SQLite**.
